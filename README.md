
# Accessible Design Co.

## Project Description

Accessible Design Co. is a fictional company website created for my Per Scholas HTML and CSS Skills-Based Assessment.

The purpose of this project is to practice building a responsive and accessible webpage using HTML5 and CSS3.

The website includes a navigation bar, hero section, About Us section, service cards, contact form, and footer.

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Interact with Web Standards Book
